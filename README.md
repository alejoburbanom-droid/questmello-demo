# QuestMello — free interactive preview

**Little quests. Big memories.**

QuestMello is an experimental personalized birthday treasure hunt for adults organizing parties for children aged 6–12. This is a **free demo**, not a paid product.

## How to use

Open [index.html](./index.html) in a browser. Enter a hero name, choose an age tier, theme and hiding locations; generate the game, then print the host kit. The adult hides five clue cards before play. Use the same device for the adventure.

## Project status

- Five stages; pirate and space themes; two age tiers and two placement sets.
- Runs as a static site. No accounts, backend, tracking, API keys, payment collection or external scripts.
- Personalization occurs in the browser. Adults supervise all activities.
- Name and trademark availability have **not** been cleared.
- Revenue: $0. Purchases: 0. Product-market fit: not validated.

Verify the URL displayed by GitHub after deployment. Do not assume the site is live until checked.
